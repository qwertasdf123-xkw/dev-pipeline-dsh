# Stage 07: Verify 验证（原 Test 泛化）

> 阶段目标: 验证实现满足验收标准（有测试跑测试，无测试用验收清单）

## 触发
`验证 / 跑测试 / 检查验收`

## agent 做
1. 有测试的项目: 跑完整测试集（用宿主 shell 执行），生成覆盖率报告
2. 无测试的项目（配置/文档/环境类）: 按 spec 验收标准逐项核验（验收清单）
3. 对照 spec.md 验收标准逐项标记: 通过 / 偏差（记录原因）
4. 必要时委托子 agent 独立复核（无委托能力时，在 gate-report 标注"未独立复核"）

## 人类做
1. 确认验收标准达成
2. 对偏差项决策（接受 / 修复）

## Done 标准
- 测试报告 + 覆盖率（有测试时）或验收清单全过（无测试时）
- 偏差项已记录并决策

## 时间盒
- L1: 30 min；L2: +CI 覆盖度门槛

## 退出条件
`Gate Report approve → Stage 8 Audit`

## 安全边界
- 不跳过失败用例；偏差不隐瞒，如实报告
