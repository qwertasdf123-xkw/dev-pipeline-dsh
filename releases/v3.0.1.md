## 可复现构建

```bash
NAME=dev-pipeline-dsh
cd <skills-root>
find "./$NAME" -exec touch -t 202610270000 {} +
find "./$NAME" -type f \
  | sed "s|^\./$NAME/||" \
  | grep -Ev '^(releases/|VERSION$|\.gitignore$|scripts/__pycache__/)' \
  | LC_ALL=C sort | sed "s|^|./$NAME/|" \
  | zip -X -q "$NAME.skill" -@
sha256sum "$NAME.skill"
```
