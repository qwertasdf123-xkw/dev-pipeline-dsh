# Stage 05: Setup 环境搭建 / 存量改造

> 阶段目标: 开发环境可跑通；存量项目先盘点现状再最小侵入改造

## 触发
`搭环境 / 初始化 / 盘点现状 / 开始改造`

## agent 做
1. 全新项目: 初始化仓库/目录结构，依赖安装（用宿主 shell 执行），验证 dev 环境可用
2. 存量改造（v2）:
   - 盘点现状（读配置、列目录、确认基线版本）
   - 改造方案最小侵入: diff 式变更 + 备份点（_backup_YYYYMMDD）
   - 每步可回滚: 变更前记录恢复命令
   - 验证改造点可运行
3. 记录启动命令与环境约束

## 人类做
1. 提供环境约束（网络/工具链/授权范围）
2. 确认备份点位置与回滚策略

## Done 标准
- 环境可跑通（或改造点已验证）
- 启动命令与恢复命令已记录
- 备份点存在（存量改造时）

## 时间盒
- L1: 10-30 min；L2: +CI 配置

## 退出条件
`Gate Report approve → Stage 6 Code`

## 安全边界
- 不装未知来源二进制；不改系统级配置
- 存量改造不动与任务无关的文件（记录基线）
