# v3.0 · 可移植版

从 DSH 专属版升级为宿主无关版：工具依赖收敛为 12 个能力槽，跨平台路径打通，并修掉了 v1.0 里全线低估 2.5~3 倍的 token 预算表。

> 命名说明：v1.0 是 GitHub release 号，v2 是 SKILL.md 内部代号（DSH agent v2）。本版统一为 v3.0。

## 安装

**方式一：release 附件**

下载 `dev-pipeline-dsh.skill`（33.2 KB，30 个条目），在 Kimi Work 中安装。

校验下载完整性：

```bash
sha256sum dev-pipeline-dsh.skill
# 08e0942fa16fe34df892ab26336fad19592c5ea999c8cc8a6322a8e9a2667700
```

**方式二：源码**

```bash
git clone https://github.com/qwertasdf123-xkw/dev-pipeline-dsh.git \
  <skills-root>/dev-pipeline-dsh
```

`<skills-root>` 按宿主而定：DSH 为 `%USERPROFILE%\.dsh\skills`，其他宿主见 `runtime-adapter.md` §6。

> 仓库根目录**就是** skill 本体（`SKILL.md` 在根，不在子目录）——克隆下来直接可用，无需再套一层目录。

### 自行构建资产（可复现）

附件是**确定性构建**产物：固定时间戳 + 显式排序，任何人构建都得到相同字节与相同 SHA-256。

```bash
NAME=dev-pipeline-dsh
cd <skills-root>
find "./$NAME" -exec touch -t 202610220000 {} +
find "./$NAME" -type f \
  | sed "s|^\./$NAME/||" \
  | grep -Ev '^(releases/|VERSION$|\.gitignore$)' \
  | LC_ALL=C sort | sed "s|^|./$NAME/|" \
  | zip -X -q "$NAME.skill" -@
sha256sum "$NAME.skill"   # 应等于上面那个 hash
```

> 三个关键点：固定时间戳（不受构建时刻影响）、`LC_ALL=C sort` 显式排序（不受 readdir 顺序影响）、排除 `releases/` 与 `VERSION`（避免"说明里含 hash、hash 又取决于说明"的循环依赖）。

## v3.0 包含

### 1. 运行时适配层（新增 `runtime-adapter.md`）

- **12 个能力槽 C1~C12**：读文件 / 写文件 / 执行命令 / 后台任务 / 委托子 agent / 结构化提问 / 跨轮次目标 / 步骤清单 / 联网调研 / 加载 skill / 大规模编排 / 治理运行时。宿主差异**只在这一处**收敛
- **能力探测协议**：首次激活把宿主工具映射写入 `.dev/runtime.json`，探测一次、缓存复用；换宿主或某槽缺失时才重读 adapter
- **降级规则**：不可降级项（门禁确认 / 制品落盘 / 决策留痕）缺失即 **STOP**；可降级项（提问 / 后台 / 委托 / 调研）必须保持语义等价，不许缩水
- **跨平台路径**：一律相对工作区根表达，Windows / POSIX 双写法，不再出现盘符绝对路径

### 2. 门禁语义加固

> 铁律：**门禁语义不可降级，工具实现可以降级。**

- 宿主无多选提问能力时 → 退化为**文本三选项 + 显式停下等下一条回复**
- 明确 **3 条禁止项**：把沉默当 approve ❌｜复用上一阶段的 approve ❌｜同一轮里既提问又推进 ❌
- 新增**状态回写**流程：用户选择 → 写回 gate-report frontmatter → 记 decision-log → 更新 STATUS → 才推进
- `C6`(提问) / `C1C2`(读写) 缺失 → STOP 报错，**绝不假装通过**

### 3. 工具解绑

SKILL.md 的「DSH 工具映射」改为「能力槽映射」（保留 DSH 原生列作对照）。stages/ 与 templates/ 中的宿主专名全部清除：`pwsh` / `ask_user_question` / `create_goal` / `job_output` / `workflow` / `web_search` / `todo_write` → 改为能力槽引用。Windows 盘符路径（`E:\test`、`C:\Users\...\.dsh`）同步清除。

### 4. 预算修正（v1.0 全线低估 2.5~3 倍）

| 项 | v1.0 声称 | v3.0 实测 |
|---|---|---|
| SKILL.md | ~260 | **1950** |
| loading.md | ~320 | **1185** |
| L1 规则 | ~200 | **361** |
| L2 规则 | ~150 | **503** |
| L3 规则 | ~300 | **841** |
| L1 启动总 | ~1000 | **~4100** 稳态 / **~7000** 首次 |

口径：中文 1 字 ≈ 1 token、ASCII 4 字符 ≈ 1 token，保守估计（较 cl100k 偏高 5~15%，用于预算规划偏安全）。

### 5. 其他改进

- 新增 `VERSION` 文件与本说明文件（仓库内版本化，不再只挂在 release body 上）
- `.dev/runtime.json` 纳入上下文压缩的保留清单（能力映射丢了就得重新探测）
- `templates/STATUS.md` 增 `宿主` / `模式` 字段；`goal_id` 改为宿主无关的 `目标`
- `templates/state-preservation.md` 明确区分「压缩**前**的 7 项检查」（在 `loading.md`）与「压缩**中/后**的分诊收尾」（在本文件）
- `templates/gate-report.md` 增「未独立复核」标注要求（无委托能力时不得冒充独立验证）
